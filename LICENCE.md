## 🧩 About

**GTFO ESP Menu** is a curated list of GTFO open-source tools:

- **Overlays** — on-screen helpers, layout notes, objective tracker, item ping display
- **Quality-of-Life Helpers** — loot catalog, loadout notes, overlay notes
- **Research Notes** — expedition layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Objective Tracker — follow mission steps on screen
- Item Ping Notes — highlight nearby resource crates
- Run Notes — record and review expedition runs
- Playback Speed — adjust editor playback for study (0.1x to 5x)

### Wallhack
- Loot Catalog — browse resource types, colors, and pickups
- Custom Loadout Notes — organize weapon and tool choices
- Visibility Notes — improved contrast for dark corridors

### Aimbot
- Stealth Study Notes — segment study on any level layout
- Alarm Control Notes — manually review alarm states in the editor
- Jump Buffer Notes — chain complex maneuvers in the editor
